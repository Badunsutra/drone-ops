# Описание проекта

## Название

**DroneOps Playground**

## Назначение

Учебная realtime sandbox-система для моделирования автономного флота дронов.

Проект нужен для практического изучения:

- F# domain modeling;
- Akka.NET actor model;
- Akka.Hosting в ASP.NET Core;
- SignalR realtime transport;
- Web/WPF визуализации;
- supervision, telemetry, throttling, dead letters;
- постепенного перехода от чистых функций к actor runtime.

## Сценарий

На дискретной карте размещены дроны, зарядные станции, точки pickup/dropoff, препятствия и операторские команды. Пользователь запускает симуляцию, создаёт задания и наблюдает выполнение миссий.

Каждый дрон является автономной state machine: он хранит собственную позицию, батарею, маршрут, текущую миссию и статус. Решение о необходимости зарядки принимает сам `DroneActor`.

## Что должен уметь MVP

- Создавать карту 20x20.
- Создавать несколько дронов.
- Создавать миссии pickup/dropoff.
- Назначать миссии свободным дронам.
- Двигать дроны по маршруту на каждом simulation tick.
- Уменьшать заряд батареи при движении.
- Отправлять дрона на зарядку по решению самого `DroneActor`.
- Передавать состояние в UI через SignalR.
- Ограничивать частоту UI-обновлений через throttled snapshot.

## Не входит в MVP

- Реальная аэродинамика или физика полёта.
- 3D-графика.
- Кластеризация Akka.NET.
- Persistence/event sourcing.
- Akka.Streams для телеметрии.
- Сложная маршрутизация с динамическими препятствиями.

## Главная учебная ценность

Проект показывает, где actor model действительно полезна:

- много независимых сущностей со своим состоянием;
- конкурентная обработка команд;
- асинхронные события;
- supervision;
- realtime-наблюдение;
- отказоустойчивость;
- явное владение состоянием.

При этом проект избегает искусственного превращения чистых функций в акторы. Планирование маршрута в MVP — обычный F#-модуль `RouteEngine`, а не `RoutePlannerActor`.
