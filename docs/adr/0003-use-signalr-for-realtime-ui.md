# ADR 0003: Использовать SignalR для realtime UI

## Статус

Принято.

## Контекст

UI должен видеть изменение состояния симуляции в реальном времени:

- движение дронов;
- изменение батареи;
- назначение заданий;
- завершение миссий;
- инциденты;
- pause/resume.

Обычный HTTP polling будет менее удобен и хуже отражает realtime-природу проекта.

## Решение

Использовать ASP.NET Core SignalR.

## Последствия

Плюсы:

- сервер может push-ить обновления клиентам;
- подходит и для Web UI, и для WPF-клиента;
- хорошо интегрируется с ASP.NET Core;
- можно отправлять snapshots и events.

Минусы:

- нужно следить за частотой отправки сообщений;
- желательно отделить доменные события от UI DTO;
- нужно учитывать reconnect и состояние клиента.
