# ADR 0001: Использовать F# для доменной модели

## Статус

Принято.

## Контекст

Проект DroneOps содержит много состояний, событий и команд. Для описания такой модели удобно использовать algebraic data types:

- records;
- discriminated unions;
- option;
- pattern matching;
- immutable state.

## Решение

Доменная модель проекта пишется на F#.

## Последствия

Плюсы:

- выразительная модель состояний;
- меньше nullable-сценариев;
- удобно описывать команды и события;
- хорошо подходит для actor messages.

Минусы:

- требуется привыкнуть к порядку файлов;
- часть .NET-инфраструктуры может быть проще на C#;
- некоторые библиотеки имеют C#-first документацию.
