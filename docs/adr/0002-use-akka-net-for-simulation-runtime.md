# ADR 0002: Использовать Akka.NET для runtime симуляции

## Статус

Принято.

## Контекст

В проекте много независимых сущностей:

- дроны;
- зарядные станции;
- диспетчер заданий;
- симуляционный мир;
- telemetry pipeline.

Каждая сущность имеет своё состояние и взаимодействует с другими сущностями асинхронно.

## Решение

Использовать Akka.NET как основной runtime для actor-системы.

## Последствия

Плюсы:

- естественная модель независимых сущностей;
- изоляция состояния;
- message passing;
- supervision;
- возможность изучить Akka.Persistence, Akka.Streams и Akka.Cluster.

Минусы:

- выше сложность, чем у обычного service-класса;
- нужно аккуратно проектировать протоколы сообщений;
- debugging сложнее, чем в синхронном коде.
